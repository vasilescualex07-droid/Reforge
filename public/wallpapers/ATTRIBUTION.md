# Wallpaper Attribution

This directory ships with Reforge. Per the project's Development Standards
(Standard A §6), third-party assets are attributed **alongside the file**.

- `static/` — 30 images sourced from **Unsplash** (Unsplash License, see
  `../../THIRD_PARTY_NOTICES.md`). Credits are the photographers' Unsplash
  names; exact per-photo records were captured at download time via the
  Unsplash API collection used for this bundle.

  `../../THIRD_PARTY_NOTICES.md`).

Both licenses permit free personal and commercial use. If you redistribute
